# ADR-0001 — บันทึกการตัดสินใจด้านสถาปัตยกรรม

**สถานะ:** ยอมรับแล้ว  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## บริบท

แอปนำเสนอข้อมูลภัยพิบัติในญี่ปุ่น 13 ภาษา โดยต้องไม่ทำให้เข้าใจว่าเป็นบริการเตือนภัยฉุกเฉินทางการ

## การตัดสินใจ

คง Expo SDK 58, React Native และ JavaScript พร้อมบรรจุ Leaflet ใน WebView เพื่อให้ใช้กับ Expo Go ได้ ใช้แผนที่ OSM Japan ขอบเขตพื้นที่ JMA ที่ตรวจสอบแล้ว และข้อมูลจุดอพยพ GSI แยกรายงานแผ่นดินไหว/สึนามิ P2PQuake จาก JMA Worker ที่เลือกเปิดได้และอ่านเฉพาะหัวข้อข่าว บันทึกภาษา/ธีมในเครื่องและขอสิทธิ์ตำแหน่งเฉพาะขณะใช้งาน

- **Time:** `src/dateTime.cjs` shows bulletin time in `Asia/Tokyo` and prefixes same-day notices with the locale's “Today”.
- **Severity:** `src/hazardSeverity.cjs` uses source-provided JMA Shindo or tsunami grade. Unknown or canceled notices remain neutral.
- **Readings:** `src/i18n.js` maintains 13 languages; the picker says `日本語` (no Romaji). Only verified Japanese readings are displayed elsewhere.
- **UI:** Semantic iOS Light/Dark colors, 44pt minimum action targets, VoiceOver labels, safe-area layout and scalable text. Follow Apple HIG; do not claim Apple certification.

## ผลกระทบและความปลอดภัย

WebView ช่วยเลี่ยง native map build แต่ยังต้องใช้อินเทอร์เน็ตและทดสอบการเข้าถึง JMA Worker ไม่รับรองคำเตือนที่ยังมีผล iOS ใช้สีระบบและพื้นที่สัมผัสที่เหมาะสม

เครือข่ายหรือแผนที่อาจใช้ไม่ได้ ประกาศเก่าไม่ใช่หลักฐานว่าคำเตือนยังมีผล ห้ามคาดเดาคำอ่าน Romaji ความรุนแรง การแพร่กระจายของสึนามิ สถานะเปิดจุดอพยพ พิกัดหรือสถานะคำเตือน

## ทางเลือกที่ไม่เลือก

- Native MapLibre/Google Maps requirement: rejected for Expo Go compatibility and keyless setup.
- Guessing hazard intensity, tsunami wavefronts, or translating emergency measurements automatically: rejected for safety.
- A permanent GPS/background alert pipeline: not implemented in this app; must not be promised.
