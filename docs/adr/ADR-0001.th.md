# ADR-0001 — บันทึกการตัดสินใจด้านสถาปัตยกรรม

**สถานะ:** ยอมรับแล้ว  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## บริบท

แอปนำเสนอข้อมูลภัยพิบัติในญี่ปุ่น 13 ภาษา โดยต้องไม่ทำให้เข้าใจว่าเป็นบริการเตือนภัยฉุกเฉินทางการ

## การตัดสินใจ

ใช้ Expo SDK 58, React Native และ JavaScript โดย iOS ใช้ Apple Maps แบบ native ผ่าน`react-native-maps`(`src/AppleSafetyMap.js`) ส่วน Android ใช้ Leaflet และ OSM Japan ใน`react-native-webview` ทั้งสองแพลตฟอร์มแสดงเฉพาะขอบเขตแผ่นดินไหว/สึนามิ JMA ที่ตรวจสอบแหล่งข้อมูลแล้ว และจุดอพยพ GSI แยกรายงาน P2PQuake จาก JMA Worker ทางเลือกที่แสดงเฉพาะหัวข้อข่าว บันทึกภาษาและธีมในเครื่อง ขอสิทธิ์ตำแหน่งเฉพาะขณะใช้งาน

- **Time:** `src/dateTime.cjs`แสดงเวลาประกาศตาม`Asia/Tokyo`และคำว่า 'วันนี้' สำหรับข่าวในวันเดียวกัน
- **Severity:** `src/hazardSeverity.cjs`ใช้เฉพาะระดับ Shindo และสึนามิที่ประกาศจริง ข่าวที่ไม่ยืนยันหรือยกเลิกใช้สีเป็นกลาง
- **Readings:** `src/i18n.js`รองรับ 13 ภาษา ตัวเลือกภาษาแสดง`日本語`โดยไม่มี Romaji และใช้การอ่านที่ตรวจสอบแล้วเท่านั้น
- **UI:** ใช้สี Light/Dark ตามความหมาย พื้นที่สัมผัสอย่างน้อย 44pt คำอธิบายสำหรับ screen reader safe area และตัวอักษรปรับขนาดได้ การยึด Apple HIG ไม่เท่ากับได้รับการรับรอง
- **Alarm:** `src/userAlert.cjs` และ `src/alarmNotify.js` แสดงการเตือนภายในแอป (การสั่นและการแจ้งเตือนภายในเครื่องแบบเลือกได้ผ่าน `expo-notifications`) เฉพาะเมื่อแอปอยู่เบื้องหน้าและประกาศล่าสุดครอบคลุมตำแหน่งอุปกรณ์ที่ผู้ใช้ยินยอม ได้แก่ อยู่ภายในพื้นที่ของ JMA ที่มี Shindo 4 ขึ้นไปหรือพื้นที่คาดการณ์ของการเตือนภัยแผ่นดินไหวล่วงหน้า อยู่ห่างจากจุดเหนือศูนย์เกิดแผ่นดินไหวไม่เกิน 50 km เมื่อไม่พบรูปทรงพื้นที่ที่ตรงกัน หรืออยู่ห่างจากชายฝั่งที่ JMA คาดการณ์สึนามิไม่เกิน 10 km โดยไม่ใช้ push token เซิร์ฟเวอร์ หรือตำแหน่งเบื้องหลัง

## ผลกระทบและความปลอดภัย

Apple Maps บน iOS ต้องทดสอบ native ด้วยอุปกรณ์จริง ส่วน Leaflet บน Android ยังต้องใช้อินเทอร์เน็ตโหลด tile ต้องตรวจ accessibility แยกแต่ละแพลตฟอร์ม JMA Worker ไม่รับรองคำเตือนที่ยังมีผล

เครือข่ายหรือแผนที่อาจใช้ไม่ได้ ประกาศเก่าไม่ใช่หลักฐานว่าคำเตือนยังมีผล ห้ามคาดเดาคำอ่าน Romaji ความรุนแรง การแพร่กระจายของสึนามิ สถานะเปิดจุดอพยพ พิกัดหรือสถานะคำเตือน

## ทางเลือกที่ไม่เลือก

- Native MapLibre หรือบังคับ Google Maps: ไม่เลือกเพื่อคง Expo Go และ Android map แบบไม่ต้องใช้ API key
- การคาดเดาระดับ Shindo หรือการแพร่ของสึนามิและการแปลตัวเลขสำคัญอัตโนมัติ: ห้ามเพื่อความปลอดภัย
- Background GPS และ emergency push ต่อเนื่อง: ยังไม่ได้พัฒนาและห้ามอ้างว่ามี

**อ้างอิงโค้ด:** `App.js`, `src/SafetyMap.js`, `src/data.js`, `src/hazardZones.cjs`, `server/worker.js`, `app.config.js`, `src/userAlert.cjs`, `src/alarmNotify.js`.
