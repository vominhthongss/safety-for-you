# ADR-0001 — Architecture decisions

**Status:** Accepted  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## Context

Japan-facing disaster information must be understandable across 13 languages without suggesting that the app is an official emergency warning service.

## Decision

Use Expo SDK 58, React Native and JavaScript. iOS uses native Apple Maps through `react-native-maps` (`src/AppleSafetyMap.js`); Android embeds Leaflet and OSM Japan raster tiles in `react-native-webview`. Both platforms render source-backed JMA earthquake/tsunami zones and GSI evacuation locations. P2PQuake reports remain separate from the optional JMA headline-only Worker. Save language/theme settings on-device and request foreground-only location.

- **Time:** `src/dateTime.cjs` renders issue times in `Asia/Tokyo` and marks same-day items as “Today”.
- **Severity:** `src/hazardSeverity.cjs` uses only published JMA Shindo and tsunami grades; unverified or canceled items are neutral.
- **Readings:** `src/i18n.js` defines 13 locales. The language picker shows `日本語` without Romaji; elsewhere use verified readings only.
- **UI:** Use semantic Light/Dark colors, 44pt touch targets, screen reader labels, safe areas and scalable text; Apple HIG is guidance, not certification.

## Consequences and safety

Apple Maps requires native-device verification on iOS, while the bundled Android Leaflet engine still needs online map tiles. Test both accessibility paths separately. The optional JMA Worker does not prove that a warning is currently active.

Network feeds and map tiles can fail; historical bulletins are not proof of an active warning. Romaji for unknown Kanji can be wrong. Never invent intensity, wave propagation, live shelter status, coordinates or current warning validity.

## Rejected alternatives

- Native MapLibre or mandatory Google Maps: not adopted for Expo Go compatibility and keyless Android maps.
- Invented hazard intensity, tsunami wavefronts, or automatically translated critical measurements: prohibited for safety.
- Background GPS and continuous emergency push alerts: not implemented and must not be advertised.
