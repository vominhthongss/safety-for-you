# ADR-0001 — Architecture decisions

**Status:** Accepted  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## Context

Japan-facing disaster information must be understandable across 13 languages without suggesting that the app is an official emergency warning service.

## Decision

Keep the mobile client on Expo SDK 58, React Native and JavaScript. Bundle Leaflet in a WebView for Expo Go compatibility; use OSM Japan raster tiles, verified JMA area geometry and GSI evacuation-place data. Keep P2PQuake earthquake/tsunami reports separate from the optional JMA headline-only Worker. Store language/theme preferences locally and request foreground location only.

- **Time:** `src/dateTime.cjs` shows bulletin time in `Asia/Tokyo` and prefixes same-day notices with the locale's “Today”.
- **Severity:** `src/hazardSeverity.cjs` uses source-provided JMA Shindo or tsunami grade. Unknown or canceled notices remain neutral.
- **Readings:** `src/i18n.js` maintains 13 languages; the picker says `日本語` (no Romaji). Only verified Japanese readings are displayed elsewhere.
- **UI:** Semantic iOS Light/Dark colors, 44pt minimum action targets, VoiceOver labels, safe-area layout and scalable text. Follow Apple HIG; do not claim Apple certification.

## Consequences and safety

WebView maps require internet imagery and manual accessibility checks, but avoid a native map build. The JMA Worker is optional and cannot claim real-time verified warning levels. Native iOS UI uses semantic colors and accessible touch targets.

Network feeds and map tiles can fail; historical bulletins are not proof of an active warning. Romaji for unknown Kanji can be wrong. Never invent intensity, wave propagation, live shelter status, coordinates or current warning validity.

## Rejected alternatives

- Native MapLibre/Google Maps requirement: rejected for Expo Go compatibility and keyless setup.
- Guessing hazard intensity, tsunami wavefronts, or translating emergency measurements automatically: rejected for safety.
- A permanent GPS/background alert pipeline: not implemented in this app; must not be promised.
