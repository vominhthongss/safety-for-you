# ADR-0001 — စနစ်ဖွဲ့စည်းပုံ ဆုံးဖြတ်ချက်မှတ်တမ်း

**အခြေအနေ:** လက်ခံပြီး  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## နောက်ခံ

ဂျပန်နိုင်ငံ၏ သဘာဝဘေးသတင်းကို ဘာသာစကား ၁၃ မျိုးဖြင့် ပြသရာတွင် တရားဝင် အရေးပေါ်သတိပေးစနစ်ဟု မထင်မှတ်စေရပါ။

## ဆုံးဖြတ်ချက်

Expo SDK 58၊ React Native နှင့် JavaScript ကို ဆက်လက်အသုံးပြုသည်။ Expo Go နှင့် ကိုက်ညီရန် Leaflet ကို WebView အတွင်း ထည့်သွင်းထားပြီး OSM Japan မြေပုံ၊ အတည်ပြုထားသော JMA နယ်နိမိတ်နှင့် GSI ဘေးလွတ်ရာနေရာ အချက်အလက်များကို အသုံးပြုသည်။ P2PQuake ငလျင်/ဆူနာမီသတင်းကို ခေါင်းစဉ်များသာ ရရှိသည့် ရွေးချယ်နိုင်သော JMA Worker နှင့် သီးခြားထားသည်။ ဘာသာစကား/အပြင်အဆင်ကို စက်အတွင်းသိမ်းပြီး app ဖွင့်ထားချိန်တွင်သာ တည်နေရာခွင့်ပြုချက်တောင်းသည်။

- **Time:** `src/dateTime.cjs` shows bulletin time in `Asia/Tokyo` and prefixes same-day notices with the locale's “Today”.
- **Severity:** `src/hazardSeverity.cjs` uses source-provided JMA Shindo or tsunami grade. Unknown or canceled notices remain neutral.
- **Readings:** `src/i18n.js` maintains 13 languages; the picker says `日本語` (no Romaji). Only verified Japanese readings are displayed elsewhere.
- **UI:** Semantic iOS Light/Dark colors, 44pt minimum action targets, VoiceOver labels, safe-area layout and scalable text. Follow Apple HIG; do not claim Apple certification.

## အကျိုးဆက်နှင့် ဘေးကင်းရေး

WebView မြေပုံကြောင့် native map build ထပ်မလိုသော်လည်း အင်တာနက်နှင့် accessibility စမ်းသပ်မှု လိုအပ်သည်။ ရွေးချယ်နိုင်သော JMA Worker သည် လက်ရှိသတိပေးချက်ကို အာမမခံပါ။ iOS တွင် system color နှင့် လုံလောက်သော touch area ကို သုံးသည်။

အင်တာနက် သို့မဟုတ် မြေပုံ ဝန်ဆောင်မှု ပျက်နိုင်သည်။ သတင်းဟောင်းသည် လက်ရှိ သတိပေးချက်မဟုတ်ပါ။ မစစ်ဆေးရသေးသော Romaji၊ ငလျင်ပြင်းအား၊ ဆူနာမီပျံ့နှံ့မှု၊ ခိုလှုံရာဖွင့်လှစ်မှု၊ တည်နေရာနှင့် သတိပေးချက်သက်တမ်းကို မခန့်မှန်းရပါ။

## မရွေးချယ်သော နည်းလမ်းများ

- Native MapLibre/Google Maps requirement: rejected for Expo Go compatibility and keyless setup.
- Guessing hazard intensity, tsunami wavefronts, or translating emergency measurements automatically: rejected for safety.
- A permanent GPS/background alert pipeline: not implemented in this app; must not be promised.
