# ADR-0001 — စနစ်ဖွဲ့စည်းပုံ ဆုံးဖြတ်ချက်မှတ်တမ်း

**အခြေအနေ:** လက်ခံပြီး  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## နောက်ခံ

ဂျပန်နိုင်ငံ၏ သဘာဝဘေးသတင်းကို ဘာသာစကား ၁၃ မျိုးဖြင့် ပြသရာတွင် တရားဝင် အရေးပေါ်သတိပေးစနစ်ဟု မထင်မှတ်စေရပါ။

## ဆုံးဖြတ်ချက်

Expo SDK 58၊ React Native နှင့် JavaScript ကို အသုံးပြုသည်။ iOS တွင်`react-native-maps`မှ native Apple Maps (`src/AppleSafetyMap.js`) သုံးပြီး Android တွင်`react-native-webview`အတွင်း Leaflet နှင့် OSM Japan သုံးသည်။ နှစ်ဖက်စလုံးသည် စစ်ဆေးထားသော JMA ငလျင်/ဆူနာမီ နယ်နိမိတ်နှင့် GSI ဘေးလွတ်ရာနေရာများကိုသာ ပြသည်။ P2PQuake သတင်းနှင့် ခေါင်းစဉ်သာရသော JMA Worker ကို သီးခြားထားသည်။ ဘာသာစကား/အပြင်အဆင်ကို စက်တွင်သိမ်းပြီး foreground location ကိုသာ တောင်းခံသည်။

- **Time:** `src/dateTime.cjs`သည်`Asia/Tokyo`အချိန်ပြပြီး ယနေ့ထုတ်သတင်းတွင် ယနေ့ အမှတ်အသားထည့်သည်။
- **Severity:** `src/hazardSeverity.cjs`သည် ထုတ်ပြန်ထားသော Shindo နှင့် tsunami grade ကိုသာ အသုံးပြုပြီး အတည်မပြု/ဖျက်သိမ်းထားသော သတင်းကို neutral ပြသည်။
- **Readings:** `src/i18n.js`တွင် ဘာသာစကား 13 မျိုးရှိသည်။ ရွေးချယ်မှုတွင်`日本語`ကို Romaji မပါဘဲ ပြပြီး အခြားနေရာတွင် စစ်ဆေးထားသော အသံထွက်သာ ပြသည်။
- **UI:** Light/Dark system color၊ 44pt touch target၊ screen-reader label၊ safe area နှင့် scalable text ကို ထောက်ပံ့သည်။ Apple HIG လိုက်နာခြင်းသည် Apple အသိအမှတ်ပြုခြင်း မဟုတ်ပါ။ Navigation တွင် ခေါင်းစဉ်ကြီး၊ native bar button နှင့် native ဘာသာစကား menu ပါသော `@react-navigation/native-stack` (iOS တွင် UINavigationController) ကို အသုံးပြုသည်။ အကြောင်းအရာတွင် inset-grouped စာရင်း၊ SF Symbols နှင့် ဆွဲချ၍ ပြန်လည်ဖွင့်ခြင်းကို အသုံးပြုပြီး emoji ပုံသင်္ကေတ မသုံးပါ။
- **Alarm:** `src/userAlert.cjs` နှင့် `src/alarmNotify.js` သည် အက်ပ်ကို ရှေ့တွင်ဖွင့်ထားပြီး နောက်ဆုံးထုတ်ပြန်ချက်က အသုံးပြုသူ သဘောတူထားသော စက်တည်နေရာကို ပါဝင်သည့်အခါမှသာ အက်ပ်အတွင်း သတိပေးချက် (တုန်ခါမှုနှင့် `expo-notifications` ဖြင့် ရွေးချယ်နိုင်သော local notification) ကို ပြသည်။ အခြေအနေများမှာ Shindo 4 နှင့်အထက် JMA ဧရိယာ သို့မဟုတ် ငလျင်ကြိုတင်သတိပေးချက်၏ ခန့်မှန်းဧရိယာအတွင်း၊ ဧရိယာပုံသဏ္ဌာန် မကိုက်ညီပါက ငလျင်ဗဟိုမှ 50 km အတွင်း၊ သို့မဟုတ် JMA ဆူနာမီခန့်မှန်း ကမ်းရိုးတန်းမှ 10 km အတွင်း ဖြစ်သည်။ push token၊ server သို့မဟုတ် နောက်ခံတည်နေရာ မသုံးပါ။

## အကျိုးဆက်နှင့် ဘေးကင်းရေး

iOS Apple Maps ကို အမှန်တကယ်စက်တွင် native စမ်းသပ်ရမည်။ Android Leaflet သည် online map tile လိုအပ်နေသေးသည်။ Platform တစ်ခုချင်းစီ၏ accessibility ကို စမ်းသပ်ပါ။ JMA Worker သည် လက်ရှိသတိပေးချက် အတည်မပြုနိုင်ပါ။

အင်တာနက် သို့မဟုတ် မြေပုံ ဝန်ဆောင်မှု ပျက်နိုင်သည်။ သတင်းဟောင်းသည် လက်ရှိ သတိပေးချက်မဟုတ်ပါ။ မစစ်ဆေးရသေးသော Romaji၊ ငလျင်ပြင်းအား၊ ဆူနာမီပျံ့နှံ့မှု၊ ခိုလှုံရာဖွင့်လှစ်မှု၊ တည်နေရာနှင့် သတိပေးချက်သက်တမ်းကို မခန့်မှန်းရပါ။

## မရွေးချယ်သော နည်းလမ်းများ

- Native MapLibre သို့မဟုတ် မဖြစ်မနေ Google Maps: Expo Go နှင့် API key မလိုသော Android map အတွက် မရွေးချယ်ပါ။
- စိတ်ကူးယဉ် Shindo၊ tsunami propagation နှင့် အရေးကြီးကိန်းဂဏန်းများ အလိုအလျောက်ဘာသာပြန်ခြင်း: ဘေးကင်းရေးအတွက် တားမြစ်သည်။
- Background GPS နှင့် အဆက်မပြတ် emergency push: မရေးဆွဲရသေးသဖြင့် မကြေညာရပါ။

**ကိုးကားကုဒ်:** `App.js`, `src/SafetyMap.js`, `src/data.js`, `src/hazardZones.cjs`, `server/worker.js`, `app.config.js`, `src/userAlert.cjs`, `src/alarmNotify.js`.
