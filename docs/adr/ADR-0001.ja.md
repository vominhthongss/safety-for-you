# ADR-0001 — アーキテクチャの決定記録

**状態:** 採用済み  
**Date:** 2026-11-23  
**Scope:** Safety For You · Expo SDK 58 · 13 locales

## 背景

日本の災害情報を13言語で提供しつつ、公式の緊急警報アプリであると誤解させない設計が必要です。

## 決定

Expo SDK 58、React Native、JavaScriptを採用します。iOSは`react-native-maps`によるApple Maps（`src/AppleSafetyMap.js`）、Androidは`react-native-webview`内のLeafletとOSM Japanを使用します。両環境とも出典を確認したJMAの地震・津波区域およびGSI避難場所を表示します。P2PQuake情報と、見出しのみを扱う任意のJMA Workerを区別します。言語とテーマは端末内に保存し、位置情報は利用中のみ取得します。

- **Time:** `src/dateTime.cjs`は`Asia/Tokyo`で発表時刻を表示し、当日の情報に「今日」を付けます。
- **Severity:** `src/hazardSeverity.cjs`は公表された震度・津波警報区分のみ使用し、不明・解除済み情報は中立色で示します。
- **Readings:** `src/i18n.js`は13言語に対応します。言語選択の`日本語`にはローマ字を付けず、他の場所でも確認済みの読みだけを表示します。
- **UI:** ライト・ダークの意味に応じた配色、44pt以上のタップ領域、読み上げラベル、セーフエリア、拡大文字に対応します。Apple HIGに従うことは認証を意味しません。
- **Alarm:** `src/userAlert.cjs`と`src/alarmNotify.js`は、アプリが前面にあり、同意を得た端末の位置が最新の発表に含まれる場合に限り、アプリ内警報（振動と、`expo-notifications`による任意のローカル通知）を出します。条件は、震度4以上の気象庁区域または緊急地震速報の予想区域の内側、区域形状が一致しない場合は震央から50 km以内、または気象庁の津波予報沿岸から10 km以内です。プッシュトークン、サーバー、バックグラウンド位置情報は使用しません。

## 影響と安全上の制約

iOSのApple Mapsは実機でのネイティブ検証が必要です。AndroidのLeafletは地図タイルの通信を必要とします。両環境のアクセシビリティを個別に確認してください。任意のJMA Workerは現行警報を証明しません。

通信障害で地図や情報が取得できない場合があります。過去の発表は警報の継続を意味しません。未確認のローマ字読み、震度、津波伝播、避難所の開設状況、地点や警報の有効性を推測しません。

## 採用しなかった案

- ネイティブMapLibreやGoogle Maps必須化：Expo Go対応とAPIキー不要のAndroid地図を維持するため不採用。
- 震度・津波伝播の推測や重要数値の自動翻訳：安全上の理由で禁止。
- バックグラウンドGPSや常時緊急プッシュ通知：未実装であり提供を約束しません。

**参照コード:** `App.js`, `src/SafetyMap.js`, `src/data.js`, `src/hazardZones.cjs`, `server/worker.js`, `app.config.js`, `src/userAlert.cjs`, `src/alarmNotify.js`.
