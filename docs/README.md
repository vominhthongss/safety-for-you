# Safety For You — Documentation / Tài liệu / ドキュメント

All 13 selectable app languages have an introduction, deployment guide and seven architecture decisions. New decisions must retain the same ADR number across translations. These documents describe implemented behavior; existing UI translation coverage outside Japanese, English and Vietnamese remains partial.
